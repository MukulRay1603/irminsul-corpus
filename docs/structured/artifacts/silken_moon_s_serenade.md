# Silken Moon's Serenade - Artifact Set

**2-Piece Bonus:** Energy Recharge +20%.
**4-Piece Bonus:** When dealing Elemental DMG, gain the Gleaming Moon: Devotion effect for 8s: Increases all party members' Elemental Mastery by 60/120 when the party's Moonsign is Nascent Gleam/Ascendant Gleam. The equipping character can trigger this effect while off-field. All party members' Lunar Reaction DMG is increased by 10% for each different Gleaming Moon effect that party members have. Effects from Gleaming Moon cannot stack.

**Plume:** Pristine Plume of the Blessed
**Sands:** Frost Devotee's Delirium
**Goblet:** Joyous Glory of the Pure
